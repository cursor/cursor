# Grok Bot access

Private linked web surface for **Grok Bot**. Signed-in Cursor viewers see their
name (via app identity) and can open the desktop agent through `grokbot://` /
`sand://`.

## Local preview

```bash
cd grok-bot-access
npm start
# http://127.0.0.1:4173
```

Local requests use a **simulated** viewer from `cursor/identity.dev.js` — not a
real sign-in. Publish as **private** so the live gate issues verified identity.

## Identity (apps-identity)

- Server-only: `api/viewer/route.js` uses `requireIdentity` from `cursor/identity.js`
- CTAs stay disabled until the viewer is verified
- Browser receives `{ name, verified, kind, simulated, … }` only — never the token
- Local `cursor/identity.dev.js` is a private-app simulated viewer (no team role)
- Generated by `cursor-cloud-add-app-identity`; do not hand-edit `identity.js`
